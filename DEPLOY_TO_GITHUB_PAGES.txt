Cafe Cinema — GitHub Pages deployment

1) Sign in to GitHub.
2) Create a NEW PUBLIC repository. Recommended name: cafe-cinema
3) Upload ALL files from this folder to the repository root.
   The index.html file must be at the repository root.
4) Open repository Settings -> Pages.
5) Under Build and deployment, choose:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
6) Save.
7) Wait a few minutes. GitHub will show the published site URL in Settings -> Pages.

The included .nojekyll file prevents GitHub Pages from trying to process the site with Jekyll.
The site is a static HTML/CSS/JavaScript site and does not require a server-side runtime.

Important:
- GitHub Pages is free for public repositories on GitHub Free.
- A custom domain is NOT included; buying one would be a separate cost.
- Availability from inside Iran cannot be guaranteed by the hosting provider. Test the final URL from an ordinary Iranian connection before replacing the Netlify link.
